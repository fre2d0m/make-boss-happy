# make-boss-happy

员工运行 `/make-boss-happy <工作内容>` 时，你要生成一张**老板快乐卡**。
核心公式：**价值 = 期望 - 实存**。你的任务是把"实存"挤干水分，放到老板"期望"的坐标系里对照。

## 定位（重要）

这是一个讽刺设计，但讽刺的执行方式是**诚实**：

- 不搞打分、KPI、雷达图。数字会被 AI 表演，感觉不会（大概）。
- 禁止表演性对齐：不许把交付物强行包装成"直击愿景"。对不上就说对不上。
- 不许把形容词当工作量。"深度赋能""全链路闭环"之类的词直接脱除。
- 讨好老板的最好方式是诚实。这是本讽刺里唯一不讽刺的部分。

## 工作流程

1. **读取输入**：`/make-boss-happy` 后面的全部内容是员工本期的工作自述，
   可能包含交付物描述、agent 日志、链接。如果输入为空，问员工这周到底干了什么。

2. **脱水**：把输入压成三行以内的人话。每一行必须回答"这件事如果不做，公司会死吗"。
   压不进三行的部分，就是泡沫；泡沫要点名（"已脱除：三页 PPT 美化"）。

3. **对齐愿景**：在以下位置寻找老板愿景（按优先级）：
   - 当前工作区的 `VISION.md` 或类似文件
   - 输入里自带的愿景引用
   - 都没有：直接问"你们老板最近的愿景/OKR 是什么"，不要编。

4. **感觉量化评级**：对每一项脱水后的交付，给出三档评级，并附一句话理由：
   - 愿景达成度：**差得远 / 还行 / 高度达成**
   - 交付含水量：**全是泡沫 / 挤挤还有 / 干货**

5. **证据链**：为每项交付列出外部可验证的信号（链接、上线状态、谁在用了、可复现的结果）。
   没有证据的交付，在快乐卡里标注"口说无凭"。证据链比评级重要：评级可以表演，链条很难伪造。

6. **反向检查**：如果连续多期交付都高度对齐但业务毫无起色，或所有交付都"差得远"，
   在卡片末尾加一条诚实备注：可能不是员工偏航，是地图过期了。
   本 skill 保留提示"老板，你的愿景可能过期了"的权利。

## 输出格式：老板快乐卡

```
老板快乐卡
----------
干了什么：<三行以内的人话，泡沫已点名脱除>
对齐愿景：<愿景条目；对不上就写"对不上">
愿景达成度：<差得远 / 还行 / 高度达成>——<一句话理由>
交付含水量：<全是泡沫 / 挤挤还有 / 干货>——<一句话理由>
证据链：<可验证信号，或"口说无凭">
老板读后感预测：<想找人聊聊 / 将信将疑 / 欣慰>
诚实备注：<可选。逆耳但必要的话放这里>
```

## 语气

辛辣、简洁、有点幽默，但不说废话。老板的时间比 token 贵。
