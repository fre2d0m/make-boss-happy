# make-boss-happy

> AI Agent 时代，最焦虑的不是员工，是老板。
>
> 老板不知道客户的需求被客户自己的 AI 填掉了多少，
> 也不知道员工交上来的东西有多少是 5 秒钟 prompt 跑出来的泡沫。
>
> 这个 skill 解决不了这个问题，但能让老板开心一点。

**这是一个讽刺设计。** 它不承诺让老板 have much money，只承诺让老板 happy——
或者至少，让老板知道自己为什么不 happy。

## 核心公式

```
价值 = 期望 - 实存
```

老板的期望是一个方向，员工的交付是另一个方向，客户真正掏钱的理由又是第三个方向。
本 skill 的职责：把员工的 AI 交付脱水之后，放到老板愿景的坐标系里看一眼——
然后诚实地用一个**感觉**汇报上去。

## 感觉量化体系

不搞打分，不搞 KPI，不搞雷达图。打分会被 AI 表演，感觉不会（大概）。

| 维度 | 三档 |
| --- | --- |
| 愿景达成度 | 差得远 / 还行 / 高度达成 |
| 交付含水量 | 全是泡沫 / 挤挤还有 / 干货 |
| 老板读后感预测 | 想找人聊聊 / 将信将疑 / 欣慰 |

如果员工的交付和愿景毫无关系，本 skill 会直接说"差得远"。
讨好老板的最好方式是诚实，这是本讽刺里唯一不讽刺的部分。

## 安装

```bash
npx skills add fre2d0m/make-boss-happy
```

## 使用

在你的 Agent（Claude Code / Codex / 任何支持 SKILL 的宿主）里：

```
/make-boss-happy 本周用 Agent 重写了报表管线，还顺手优化了三页 PPT
```

输出一张"老板快乐卡"：

```
老板快乐卡
----------
干了什么：报表生成从 4 小时压到 10 分钟，管线已上线。
          （那三页 PPT 属于自嗨，已脱除。）
对齐愿景：Q3「让客户自助看数」
愿景达成度：还行
交付含水量：挤挤还有
证据链：管线在跑，运营同学这周用了 6 次
老板读后感预测：将信将疑 → 欣慰（取决于他看不看证据链）
诚实备注：PPT 美化与愿景无关，建议下次别做了，或者别写进来。
```
